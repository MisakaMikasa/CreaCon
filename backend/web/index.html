Setup & help

1. Camera Raw settings CreaCon needs

Open Camera Raw (double-click any raw photo), click the gear icon, then File Handling.

Save image settings in → Sidecar ".xmp" files
Required. Otherwise Camera Raw keeps your develop settings in its own database, where CreaCon can neither read nor write them. Nothing will work without this.
JPEG/HEIC → Automatically open all supported JPEGs
Only needed if you want to edit JPEGs. Without it Photoshop opens them directly and skips Camera Raw entirely.

2. If colours look wrong on the canvas

On Photoshop 27.10 the canvas can render more saturated than the Camera Raw dialog showing the same photo. That is a Photoshop bug, not CreaCon. Camera Raw is the correct one, and files you save or export are unaffected.

Fix: Ctrl+K → Performance → untick "Use Graphics Processor", then restart Photoshop. 27.9.1 is unaffected; try turning it back on once 27.11 ships.

3. Using it

  1. Open a photo with the 📷 button. That is how CreaCon places it so it can be develop-edited later — a photo you opened yourself cannot be.
  2. Type what you want.
  3. Read the plan, then click Apply. Nothing touches your document until you do.
  4. Keep going. Refine, or restore an earlier state from its card.

Photoshop freezes while an edit applies. That is Photoshop, not a crash — it blocks its own interface while a script runs. This window stays responsive throughout.

Things that surprise people

An AI mask did nothing
Camera Raw loads the settings but does not always run the selection. Double-click the layer to open it in Camera Raw and click "Update AI settings" once. Gradient masks never need this.
Ctrl+Z did not undo a develop edit
Those live in a sidecar file beside your photo, which Photoshop's undo cannot reach. Use "Restore to before this" on the edit's card instead.
Editing one layer changed another
They are the same photo. A file holds one set of develop settings, so duplicated photo layers are locked together.
